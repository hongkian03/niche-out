# E1-S19 Interruption and shutdown

Recorded November 14, 2026. The [master tracker](../../IMPLEMENTATION-PLAN.md) owns status. [Integrated results and manual guide](EPIC-1-MANAGED.md).

## Implementation

Same-origin transient failures enter Reconnecting and preserve synthetic identity. Connector exit or sustained endpoint loss clears the ready invitation and requires explicit Finish/new session. No silent new-URL migration occurs. Startup cancellation, failure and normal shutdown clean up owned resources.

## Verification

A real owned connector was suspended/resumed on the Mac: readiness moved to Reconnecting and returned at the same origin/session, retaining owner access. Terminating that connector produced Failed with no public invitation; Start was refused until explicit Finish. Deterministic tests cover cleanup/reentrancy and retained application state.
