# E1-S17 Local hosting launcher

Recorded November 14, 2026. The [master tracker](../../IMPLEMENTATION-PLAN.md) owns status. [Integrated results and manual guide](EPIC-1-MANAGED.md).

## Implementation

`controller.ts` exposes an isolated loopback setup listener with private one-use access, a separate HttpOnly/SameSite cookie, exact Host/Origin policy, bounded bodies and session-fenced controls. `launch.ts` opens setup privately and supports Enter to reopen. Finish keeps local setup available; Quit closes it.

## Verification
