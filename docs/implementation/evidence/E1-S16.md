# E1-S16 Reusable tunnel manager

Recorded November 14, 2026. The [master tracker](../../IMPLEMENTATION-PLAN.md) owns status. [Integrated results and manual guide](EPIC-1-MANAGED.md).

## Implementation

`manager.ts` owns session identity, cancellable bounded startup, nonce-bound public health, same-origin monitoring and explicit failed-session handling. `connector.ts` verifies the pinned executable before spawn, isolates provider configuration/environment and owns bounded TERM/KILL cleanup. No runtime dependency download or probe expiry applies.
