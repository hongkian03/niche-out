# E1-S18 Hosting dashboard and private host access

Recorded November 14, 2026. The [master tracker](../../IMPLEMENTATION-PLAN.md) owns status. [Integrated results and manual guide](EPIC-1-MANAGED.md).

## Implementation

Local assets provide readiness, copy/manual fallback, generated/enlarged QR and private host entry. Public assets provide clearly labelled synthetic connection/upload/tab checks. `owner.ts` implements monotonic 60-second one-use tokens, rotation only on successful exchange, and role-conflict preservation. The application binds transports to their authenticated session.

## Verification

Public HTTP/auth tests cover expiry, replay, owner recovery/conflict, immutable origin, malformed targets, resource/upload bounds and transport/session binding. The real browser harness has verified exact QR payload, private host exchange/reload and public/local control isolation. The user confirmed the actual managed dashboard became Ready and its QR opened on the iPhone over cellular, with connection, upload, draft-clearing refresh and reconnect working.

Environment: Apple M3 Pro, macOS 26.5.2 arm64, Node 24.22.3/npm 11.19.1, cloudflared 2026.11.0 and Chrome 157.0.8103.51. The integrated unit/integration suite currently passes 147 tests in 11 files.
