# E1-S05 session and complete-view evidence

Discovery has distinct strict host, player and guest shapes. It identifies a removed membership separately and limits commit metadata to the current host game. A valid controlling document can receive a private continuation grant. Its persisted shape contains only instance, game, previous page ID and the 32-byte base64url proof. [Discovery contracts](../../../packages/contracts/src/session.ts) · [Wire primitives](../../../packages/contracts/src/wire.ts)

Both state events share one versioned complete-view schema. Eleven role/phase combinations cover host Setup and both roles in Lobby, Reading, Answering, Results and Finished. The host's lobby summary exposes sanitized timers/tiers and a local invitation. Untimed phases use null deadlines/rounds. Timed phases use an in-range zero-based round index. Only Results exposes current-round points and grouped canonical answers. Finished views allow one requested historical group table and a role-specific recap. ## Verification

On the Epic 1 working tree, macOS 26.5.2 arm64, Node v24.22.3, Zod 4.6.7 and Vitest 5.1.0, `npm run typecheck`, `npm test -- tests/protocol` and `npm run build --workspace ./packages/contracts` passed. The combined request/view suite includes 41 tests in two files. [View tests](../../../tests/protocol/views.test.ts) · [Discovery and acknowledgement tests](../../../tests/protocol/messages.test.ts)

The tests exercise all allowed role/phase projections, reveal timing boundaries, zero-point acceptance versus a miss, ties, empty final host standings, full-length prompts, historical-detail restrictions, alternate-role payload rejection, nested forbidden mappings, and credential/discovery limits. They reject answer-to-player associations, response-only authority fields in requests, and private host credentials embedded in invitation URLs.

Semantic provenance still requires the real engine and server. A shape validator cannot tell whether a permitted numeric published total came solely from finalized rounds or whether an own-result projection belongs to the authenticated player. E2-S08/S09 and E3-S12/S13 must test those properties on real serialized outputs. The LAN and tab probes have separate evidence in E1-S07/S08.
