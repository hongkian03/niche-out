# E1-S07 · Selected LAN origin

**PASS on a single Mac.** Ran `npm run probe:lan` with macOS 26.5.2 arm64, Node 24.22.3, Chrome 157.0.8103.51, Socket.IO client/server 4.8.4, and the en0 private IPv4 interface with a /16 mask. Used an ephemeral port, a fresh headless Chrome profile, local assets and a temporary HttpOnly SameSite=Strict cookie. Observations omit cookie values and host addresses.

| Browser request | Origin observed | Result |
| --- | --- | --- |
| First document GET | Absent | Loaded, session cookie established |
| Subsequent asset GET | Absent | Cookie returned by browser and hidden from page script |
| Polling GET | Absent | Accepted for the approved peer/Host and authenticated session |
| Polling POST | Exact selected origin | Accepted with cookie |
| WebSocket upgrade GET | Exact selected origin | Upgraded from polling; acknowledged a client event |

The selected listener rejected a deliberately mismatched Host. Polling rejected a foreign Origin and a missing cookie. The same policy function rejected missing Origin on POST and an out-of-subnet address in a controlled input. A separate smoke run exercised the manual-mode page on the host, including its UTF-8 success message. No off-subnet device or physical second device was available. The sandbox initially denied binding the selected address; the real browser run used approved local network access. The raw HTTP negative Host test uses Node's HTTP client because fetch normalizes that header.

**Handoff to E3-S01/S05/S13.** Apply peer/Host checks even when navigations and same-origin polling GETs omit Origin. Where a browser supplies Origin, require an exact match. Enforce it for mutations and WebSocket upgrades. Validate actual Fastify/Socket.IO middleware order, all served routes, raw peer addresses, and headers on other browser families; proxies and forwarded headers grant no authority. E6-S04 owns the device/network matrix. A same-host request proves browser behavior on a private origin; it cannot verify AP isolation, firewall prompts or phone reachability.
